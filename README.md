# WeNurse HubSpot-Sandbox (Freigabe)

Statische Vorschau der WeNurse-HubSpot-Ansichten – erzeugt aus `Sandbox-Matrizen.xlsx`
im Projektordner `outputs/hubspot-ansichten-sandbox`.

* Alle Ansichten: [`views/matrix-uebersicht.html`](views/matrix-uebersicht.html)
* Freigabe-Modus ohne Bedienelemente: `?pur=1` an jede Adresse anhängen
  (z. B. `views/matrix-k-na-1.html?pur=1`) – dann erscheinen nur die Karten.

Die Dateien werden automatisch erzeugt und mit `tools/github_pages.sh` hochgeladen.
Alle Datensatzwerte sind fiktiv; es sind keine echten Kontakt- oder Dealdaten enthalten.
